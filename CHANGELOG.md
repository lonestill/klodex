# Changelog

Этот файл читает встроенный просмотр «Что нового» (плашка обновления).
Формат: `## [версия] - дата`, разделы `### Добавлено / Изменено / Исправлено`, пункты — списком.

## [2.0.0] - 2026-10-28

### Добавлено
- Studio Interface v2: полноэкранная компоновка с левым навигационным рельсом, расширенным селектором моделей и поиском
- Мгновенная регистрация и авто-свап аккаунтов ADCode (Tagflow) с живым SSE-стримингом этапов и удалением исчерпанных аккаунтов
- Поддержка составных промптов (composite) с разбивкой на системную и пользовательскую части
- Кнопка принудительного обновления каталога скиллов из GitHub/Git с анимацией и визуальным статусом

### Исправлено
- Сжатие контекста (/compact) и защита от переполнения 413/400 с детерминированным fallback-саммари
- Корректный подсчёт активных токенов сессии вместо кумулятивного расхода за всё время
- Устранено смещение и зигзагообразный разрыв вертикальной линии таймлайна активности
- Снята обводка и фон с бейджа v2.0 на навигационном рельсе
- Исправлено зависание автоскролла при прокрутке вверх

## [0.1.24] - 2026-10-27

### Изменено
- Просмотр «Что нового» переработан: нормальные отступы и скролл, новая версия выделена карточкой, секции подсвечены semantic-цветами, коммиты — отдельным блоком
- Апдейтер показывает целевую версию (например, v0.1.24) вместо короткого хэша коммита
- Окно обновлений переведено на язык интерфейса; кнопка «Что нового» доступна в настройках даже без pending-обновления

## [0.1.23] - 2026-10-27

### Добавлено
- Рабочая область: панель изменений задачи — список файлов, общий diff, результаты команд, откат файла или всей итерации, коммит из результата. Контрольные точки создаются до и после каждого запуска агента
- Preview: запуск и остановка dev-сервера, страница приложения рядом с чатом, снимки desktop/mobile и отдельных элементов по CSS-селектору. Снимок прикладывается к сообщению вместе с ошибками консоли и DOM-фрагментом элемента
- Память проекта: редактируемые заметки, которые добавляются в контекст новых запусков
- Смысловое сжатие контекста: `/compact` и автоматическое сжатие готовят резюме для модели, полная история переписки сохраняется и доступна для поиска
- Swarm: каждая задача выполняется в отдельном Git worktree; `dependsOn` задаёт порядок, конфликтующие результаты остаются в worktree для ручного разбора
- Очередь задач хранится в базе и переживает перезапуск сервера; прерванный запуск можно продолжить — агент получает журнал уже выполненных операций
- Кнопка «Что нового» в плашке обновления с этим ченджлогом
